# Werewolf 20th Character Forge

A free, local-first character builder for **Werewolf: The Apocalypse 20th Anniversary Edition**.

Templates: Garou, human Kinfolk, wolf Kinfolk, and mortal NPC. The app includes Garou Nation, hive/fallen-tribe, and neutral Changing Breed terminology sets; guided creation budgets; editable supplement traits; experience purchases; local autosave; JSON import/export; and print/PDF output.

This forge shares an engraved-sigil design system, book-page workspace, controls, and print treatment with the Mage, Vampire, Wraith, and Changeling forges while retaining a Werewolf-specific moon-and-claw seal and palette.

Open `index.html` in a browser. No account, server, analytics, or network connection is required.
