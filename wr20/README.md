# Wraith 20th Character Forge

A free, local-first character builder for **Wraith: The Oblivion 20th Anniversary Edition**.

Templates: Wraith, Medium/Haunted Mortal, and mortal NPC. The app includes Hierarchy, Guild/Renegade/Heretic, and afterlife-neutral terminology sets; the separate Shadow creation budget; Passions; Fetters; Dark Passions; Thorns; editable supplement traits; experience purchases; local autosave; JSON import/export; and print/PDF output.

This forge shares an engraved-sigil design system, book-page workspace, controls, and print treatment with the Mage, Vampire, Werewolf, and Changeling forges while retaining a Wraith-specific broken-veil seal and palette.

Open `index.html` in a browser. No account, server, analytics, or network connection is required.
