# Changeling 20th Character Forge

A free, local-first character builder for **Changeling: The Dreaming 20th Anniversary Edition**.

Templates: Changeling, Kinain, Enchanted Mortal, and mortal NPC. The app includes Seelie, Unseelie, and Shadow Court/neutral terminology sets; Arts; Realms; editable supplement traits; experience purchases; local autosave; JSON import/export; and print/PDF output.

This forge shares an engraved-sigil design system, book-page workspace, controls, and print treatment with the Mage, Vampire, Werewolf, and Wraith forges while retaining a Changeling-specific four-petal seal and palette.

Open `index.html` in a browser. No account, server, analytics, or network connection is required.
